# flutter_taxi_fare_app

Assignment 05 — แอปคำนวณค่าโดยสารแท็กซี่ (Flutter)

## หน้าจอ

- `lib/views/splash_screen_ui.dart` (`SplashScreenUi`) — หน้าจอแรก แสดง 3 วินาที
- `lib/views/taxi_fare_ui.dart` (`TaxiFareUi`) — หน้าคำนวณค่าโดยสาร

## อัตราค่าโดยสารแท็กซี่มิเตอร์

- กิโลเมตรแรก: 35 บาท
- กิโลเมตรที่ 2–10: กิโลเมตรละ 6.50 บาท
- กิโลเมตรที่ 10–20: กิโลเมตรละ 7.00 บาท
- กิโลเมตรที่ 20–40: กิโลเมตรละ 8.00 บาท
- กิโลเมตรที่ 40–60: กิโลเมตรละ 8.50 บาท
- กิโลเมตรที่ 60–80: กิโลเมตรละ 9.00 บาท
- ระยะทางเกิน 80 กม. ขึ้นไป: กิโลเมตรละ 10.50 บาท
- กรณีรถติด: นาทีละ 3.00 บาท
